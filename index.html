🐗 hAI.Truffelhog

TruffleHog als Docker-Webservice mit einfacher Weboberfläche für Remote-Scans im LAN.

✨ Überblick

hAI.Truffelhog kombiniert TruffleHog mit einer schlanken Flask-Weboberfläche. So kannst du Secret-Scans für Git-Repositories zentral im Container starten, ohne TruffleHog lokal installieren zu müssen.

🧠 Features

  • Docker-Setup mit docker compose
  • Einfache Weboberfläche mit Flask
  • Remote-Scan von GitHub/GitLab/anderen Git-Servern per URL
  • Persistente JSON-Ergebnisse im Volume
  • LAN-tauglicher Betrieb

🚀 Schnellstart

  1. Repository klonen
  2. Optional .env aus .env.example anlegen
  3. docker compose up -d --build ausführen
  4. Weboberfläche öffnen: http://127.0.0.1:5000
